# cakery
A responsive and modern bakery website for showcasing delicious cakes, pastries, and desserts with an elegant UI and smooth user experience.

Welcome to the Cake Bakery Website project! This is a responsive and visually appealing website designed for a bakery or cake shop. The website showcases cakes, pastries, and desserts with a clean and modern user interface.

✨ Features

Responsive design for mobile, tablet, and desktop

Beautiful homepage with cake showcase

Product/gallery section for cakes and desserts

Navigation menu and smooth user experience

Contact section for customer inquiries

Modern UI using HTML, CSS, and JavaScript

🛠️ Technologies Used

HTML5 – Structure of the website

CSS3 – Styling and responsive design

JavaScript – Interactive features and functionality

Clone the repository:

Open the project folder:

🎯 Purpose of the Project

This project was created to practice and improve frontend web development skills, including:

Responsive web design

UI/UX design principles

HTML, CSS, and JavaScript fundamentals

Building real-world static websites
